SDK = Software Developer Kit

Language-specific APIs (set of libraries) which enables you to access and manage AWS services programmatically and can be embedded within your application. 

Languages supporting the AWS SDK include (JS, Python, PHP, .NET, Ruby, JAVA, Go, Node.js, C++). The are also mobile SDKs and IoT device SDKs so you can create mobile applications and use IoT devices such as thermal sensors or backlogs that can be connected to AWS services.

The [[AWS CLI]] is built on the AWS SDK for Python named Boto.
