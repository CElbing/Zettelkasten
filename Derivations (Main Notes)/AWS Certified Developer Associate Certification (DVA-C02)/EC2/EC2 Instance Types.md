General overview of EC2 Instance types

You can use different types of EC2 instances that are optimized for different use cases (https://aws.amazon.com/ec2/instance-types/)

To get all instances and various metrics regarding them: https://instances.vantage.sh/

AWS has the following naming convention: **m5.2xlarge**
- m: instance class
- 5: generation (AWS improves them over time)
- 2xlarge: size within the instance class
