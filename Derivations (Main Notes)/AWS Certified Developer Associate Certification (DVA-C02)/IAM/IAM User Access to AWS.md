Users can access AWS in three ways:
- AWS Management Console: protected by password + [[AWS Multi Factor Auth (MFA)]]
- [[AWS CLI ]](Command Line Interface): protected by access keys
- [[AWS SDK ]](Software Developer Kit) for code: protected by access keys

Access Keys are generated through AWS Console. Users manage THEIR OWN access keys.
**Access Keys are secret, just like a password DO NOT SHARE**

Access Key ID ~= username
Secret Access Key ~= password
