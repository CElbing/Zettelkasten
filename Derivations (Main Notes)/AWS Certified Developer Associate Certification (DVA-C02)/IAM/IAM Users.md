When you are accessing your AWS cloud console, it is best practice to NOT use the [[Root Account]]. Instead, make a new [[IAM]] user with your desired permissions and sign into that account instead. The Root Account has complete access to everything and should be kept as secure as humanly possible.

To create a new user you navigate to IAM -> IAM users. Click "create new user" and then follow the steps.

This is initially where users get assigned to groups and provided permissions.
