The shared responsibility model illustrates what YOU are responsible for and what AWS is responsible for. Essentially, AWS is responsible for their infrastructure and you are responsible for how you USE that infrastructure.
- AWS responsibilities
	- Infrastructure (global network security)
	- Configuration and vulnerability analysis
	- Compliance validation
- Your responsibilities
	- Users, Groups, Roles, Polices management and monitoring
	- Enforcing the enabling MFA on ALL accounts
	- Rotating all keys often
	- Use IAM tools to apply the appropriate permissions
	- Analyze access patters and review permissions.
